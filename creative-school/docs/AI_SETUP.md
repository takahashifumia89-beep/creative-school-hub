# Подключение ИИ-помощника

Помощник встроен в дизайн-, 3D-, фото- и видеостудию, а также творческие заметки. Он объясняет инструменты, помогает планировать работу и даёт рекомендации на русском, английском и казахском. Правки в редакторе пользователь выполняет сам. Без серверного ключа интерфейс честно показывает, что помощник ещё не подключён; остальные возможности сайта работают.

## Подключить на действующем сайте

1. Создайте отдельный ключ проекта в [OpenAI API](https://platform.openai.com/api-keys), проверьте доступ к выбранной модели и баланс API. Не публикуйте ключ и не присылайте его в переписке.
2. В Cloudflare откройте **Workers & Pages → creative-school-hub → Settings → Variables and Secrets → Add**.
3. Выберите тип **Secret**, имя **`OPENAI_API_KEY`**, вставьте значение ключа и нажмите **Deploy**. Нужен секрет работающего Worker, а не переменная сборки.
4. Откройте студию, нажмите «ИИ-помощник» и «Проверить подключение». Отправьте короткий вопрос, например «Как экспортировать PNG с прозрачным фоном?».

Ключ передаётся только из Worker в OpenAI через заголовок авторизации. Он не хранится в React, localStorage, D1, JSON проекта или GitHub. Имена `VITE_OPENAI_API_KEY` и другие клиентские переменные для него использовать нельзя. Для замены ключа обновите тот же Secret и выполните Deploy; при утечке отзовите старый ключ в OpenAI.

Для администратора с настроенным Wrangler доступен альтернативный способ из `creative-school/`:

```sh
npx wrangler secret put OPENAI_API_KEY
```

Wrangler запросит значение интерактивно. Не передавайте его аргументом командной строки. Команда создаёт и сразу публикует новую версию Worker с секретом; используйте актуальную основную ветку проекта.

## Модель и расход

По умолчанию используется `gpt-5.6-terra`, Responses API, уровень рассуждения `low`, максимум 1800 выходных токенов. Необязательная серверная переменная `OPENAI_MODEL` меняет модель. Выбранная модель должна поддерживать Responses API и `reasoning.effort: low`; доступ к ней зависит от проекта OpenAI. Значение модели нельзя передать из браузера.

Счётчики в D1 ограничивают обращения: 4 в минуту и 20 в день на аккаунт, 40 в день с одного IP, 100 в день на весь сайт. Администратор может изменить общий дневной лимит через серверную переменную `AI_DAILY_LIMIT` (целое число 1–10000); это лимит запросов, а не обещание фиксированной стоимости. День для этих счётчиков начинается в 00:00 UTC. Неудачные и прерванные после отправки попытки тоже могут использовать квоту. Настройте ограничения расхода и уведомления в проекте OpenAI перед массовым запуском.

Автоматических повторов и офлайн-очереди платных запросов нет. Worker прерывает запрос по тайм-ауту 35 секунд. Кнопка «Остановить» прекращает ожидание в браузере; уже начавшаяся обработка у провайдера может завершиться и учитываться в оплате.

## Что передаётся

При отправке вопроса в OpenAI уходят текст вопроса, до шести последних сообщений и описание доступных инструментов текущей студии. По умолчанию параметры проекта выключены. При включении соответствующей опции добавляются название и ограниченная сводка видимых слоёв/объектов, текста и настроек. Имена медиафайлов, идентификаторы кеша, координаты вершин, фото, видео и аудиофайлы из проекта не отправляются. Помощник не видит пиксели холста и не оценивает изображение или звук по фактическому содержимому.

Диалог хранится только в памяти открытой страницы, до 20 сообщений; его можно очистить или скачать. Он переживает сворачивание панели и первое сохранение нового проекта, но сбрасывается при открытии другого проекта, смене студии/аккаунта или перезагрузке страницы. Сервер приложения не записывает вопросы и ответы в D1 или журналы. Запрос к OpenAI использует `store: false`; это не отменяет все правила хранения данных самого провайдера. Не отправляйте в вопросах пароли, ключи или конфиденциальные сведения.

## Локальная проверка

Для ручной проверки создайте **неотслеживаемый** файл `creative-school/.dev.vars` и добавьте туда ключ локально. Файлы `.dev.vars*` и `.env*` исключены из Git на обоих уровнях проекта. Не используйте production-ключ в тестах и не снимайте вывод терминала с его значением.

Автоматические тесты используют подменённые ответы провайдера и не тратят API-баланс. Они проверяют серверный запрос, приватность сводок, отсутствие ключа, ошибки/тайм-ауты, историю, остановку, языки и мобильную панель. Живой ответ OpenAI необходимо проверить после добавления секрета.

Официальная документация: [секреты Cloudflare](https://developers.cloudflare.com/workers/configuration/secrets/), [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create), [модель GPT-5.6 Terra](https://developers.openai.com/api/docs/models/gpt-5.6-terra), [обработка данных OpenAI](https://developers.openai.com/api/docs/guides/your-data).
